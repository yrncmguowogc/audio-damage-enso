## Overview

Enso is a multi-layer looper inspired by modular Eurorack loopers, supporting simultaneous recording across independent lanes with per-lane speed, direction, and feedback controls.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Audio Damage Enso** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Lane Looping** | Up to eight independent playback lanes with separate loop times |
| **Speed Control** | Per-lane speed from 1/4x to 4x with smooth interpolation |
| **Reverse Playback** | Individual lane reverse without affecting other lanes |
| **Feedback Matrix** | Route lane outputs back into each other for generative textures |
